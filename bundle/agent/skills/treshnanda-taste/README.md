# treshnanda-taste

A personal **UI/UX taste skill** for Claude Code (and other agents): a warm, tactile, **dual-mode** aesthetic — bone and true-black canvases, black-pill grammar, semantic color, editorial-serif moments, concentric widget physicality, naturalistic imagery — paired with an explicit **anti-AI-pattern doctrine** and **bold, kinetic motion that's alive but never in the way**.

Built two ways at once: from hundreds of real product iterations, and from a 77-image reference library analyzed image by image — every taste rule ships with its known slop twin (what a lazy model gets wrong imitating it).

It's the *personal taste* layer that sits on top of two craft skills it **auto-loads** — [`emil-design-eng`](https://animations.dev) (craft details) and `motion-design` (motion theory). One invocation pulls the whole stack.

## Install

```bash
npx skills add Tresnanda/treshnanda-taste
```

Then start a **new** session and invoke it:

```
/treshnanda-taste
```

## What's inside

- **`SKILL.md`** — the hub: quality bar + vocabulary, working process, the cross-cutting **visual DNA** (canvas, black-pill color grammar, shadowless depth, concentric geometry, typography, imagery, contained-gradient rules), the **anti-AI-pattern doctrine** (a tell→instead table), the **universal motion doctrine** (product-agnostic laws, timing defaults, a register map that derives motion personality from any product's core verb, and a setpiece-selection rule), copy rules, UX correctness + data coherence, a pre-flight checklist, and the consolidated "never" list.
- **`reference/`** — per-surface deep dives rebuilt from per-image analysis, each with frequency-counted patterns, approximate hexes, layout archetypes, and its own premium-vs-slop deltas:
  - `landing-pages.md` (28 designs) · `desktop-app.md` (8) · `mobile-app.md` (13) · `elements.md` (~25)
  - `universal-craft.md` — surface-agnostic craft: interface copy as a design material, how to choose a typeface, building a full color system from one accent, the responsive collapse order, perceived speed (zero layout shift, optimistic UI, the latency ladder), and the meta-rule for breaking rules (one rule, loudly, on purpose).
  - `ux-psychology.md` — six engagement principles for onboarding / signup / pricing / upgrade flows (smart defaults, goal gradient, reciprocity, IKEA effect, loss aversion, anchoring), constrained to a premium, no-dark-patterns register.
- **`FABLE.md`** — an author's note from the model that remade this skill: what it believes beyond the rules (taste as compressed care, the gravity toward the mean, calm over magic, design as the ethics of attention). Optional reading, for when you're stuck.
- **`animation-vocabulary.md`** — a shared glossary of animation patterns (e.g. *shared element transition, morph, rubber-banding, stagger, follow-through, squash & stretch*) so motion requests are unambiguous.

## Use it anywhere

Built to apply to **any app or website**, not one product. Take the instincts, not any single product's decisions.
